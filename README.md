# Markdown 阅读器（网页版）

一个单文件、零依赖的 Markdown 阅读器，打开即用。

## 功能
- 拖拽 `.md` / `.txt` 文件到窗口即可阅读
- 直接 `Ctrl + V` 粘贴 Markdown 文字
- 点击「打开文件」选择本地文件
- 左侧编辑、右侧实时预览，自动保存
- 三套主题：浅色 / 深色 / 护眼
- 代码语法高亮、表格 / 任务列表 / 引用等完整排版
- 一键导出为独立 HTML、复制源码

## 使用
直接用浏览器打开 `index.html` 即可；或访问部署在 GitHub Pages 的在线地址。

技术栈：marked + DOMPurify + highlight.js（均通过 CDN 加载，首次需联网）。
